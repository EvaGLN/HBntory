# Minimum Viable Product
**Principle: an early vertical slice**<br>
`Week 1`: Database, a route for the stock, one MCP tool and AI can anwser one query.

**Pack 1 - Fundations**<br>
Scheme, models, seed, stock rules (stock above or equal to 0, integer and valid branche).

**Pack 2 - Security and Backoffice**<br>
Login, hashing, roles, stock operation, account management, product API.

**Pack 3 - AI and client**<br>
MCP products, stock request, AI agent, /ask, client page.

**Pack 4 - Delivery**<br>
Critical case tested, README done, demo done too.

**Postponed**<br>
Sophisticated interface, conversation history, streaming.

**If we have time**<br>
Extended testing, Docker Compose, rate limiting.

**Major risk**<br>
Late implementation.
